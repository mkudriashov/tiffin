# Contributing

Read [AGENTS.md](../AGENTS.md) before changing code. Use Python 3.14 and uv. Keep British English in UI text and documentation, no emoji in messages, and describe food as on plan or off plan rather than good or bad.

Every table outside `db.PROJECTION_TABLES` and `db.STATE_TABLES` is an append-only ledger. Add a row for a correction, and read the latest applicable row. Use `clock.utc_stamp()` for UTC space-form timestamps and `clock.today_local()` for household days; never call `datetime.now()` outside `clock.py`. Each job run must write `run_ledger` and show degraded or failed work on the owner's status strip. Scope a person's data from Telegram or web identity, never from a request argument. The model may return candidate indexes; code owns nutrient arithmetic and validates all model output. Gate AI data on per-person consent, and keep secrets out of config, the DB and logs.

Tests use fixtures, fakes for Telegram, intervals.icu and model calls, and `FrozenClock` for time. Do not point tests at a real household database. Run:

CI should test what is published, not a working copy: export the commit and run everything there (the private-string scan reads the tree, so a linked worktree's `.git` pointer file or a stray local file must not be in it).

```text
git archive --prefix=tiffin/ HEAD | tar -x -C "$RUNNER_TEMP"
cd "$RUNNER_TEMP/tiffin" && uv sync --frozen && uv run pytest -q -p no:cacheprovider && uv run ruff check . && uv run ruff format --check . && uv run pyright
```

Locally:

```text
uv sync
.venv\Scripts\python.exe -m pytest -q -p no:cacheprovider
.venv\Scripts\ruff.exe check .
.venv\Scripts\ruff.exe format --check .
.venv\Scripts\pyright.exe
```

The same commands use `.venv/bin/` executables on Unix. Add focused tests for behaviour changes. Keep documentation aligned with `config/defaults.toml`; the configuration reference is generated by `tools/generate_configuration.py` and checked by a test.
