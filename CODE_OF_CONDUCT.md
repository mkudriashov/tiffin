# Code of Conduct

Tiffin follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies to issues, pull requests, reviews and other project spaces, and to people representing the project in public spaces.

Report unacceptable behaviour to the maintainers privately through [GitHub security advisories](https://github.com/mkudriashov/tiffin/security/advisories/new), marking the report as a conduct concern. Reports will be reviewed fairly, with respect for the reporter's privacy. Community leaders may take the corrective actions described in the Contributor Covenant.
